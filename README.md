# Sistema de Gestión de Contactos

## Descripción
Proyecto desarrollado en Python para el Laboratorio N.º 5 de Fundamentos de Programación.

## Funciones
- Registrar contactos.
- Mostrar contactos guardados.
- Buscar contactos por nombre.
- Guardar información en archivos de texto.
- Guardar y recuperar datos en archivos binarios.

## Herramientas utilizadas
- Python
- Librería os
- Librería pickle
- Visual Studio Code
